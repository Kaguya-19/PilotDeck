# 文件真实 E2E 用例

## 测试数据

在隔离项目中真实创建 `README.md`、TypeScript 文件、PNG、PDF、DOCX、XLSX、PPTX、ZIP 和超大文本文件，并准备不存在路径、只读文件和无权限目录。文件内容使用唯一运行标记。

## 文件树与工作区按钮

| 用例 ID | 操作 | 预期结果 | 级别 |
|---|---|---|---|
| `FIL-TREE-001` | 打开文件区，点击目录展开/收起 | 子目录和文件正确显示；状态不影响会话 | 普通 |
| `FIL-TREE-002` | 点击刷新、文件搜索、清空搜索 | 列表反映磁盘最新状态；搜索结果和空结果正确 | 普通 |
| `FIL-TREE-003` | 点击不同文件和目录 | 选中态、面包屑和预览内容同步；General 项目按产品规则禁用文件能力 | 普通 |
| `FIL-WORKBENCH-001` | 点击文件目录/智能聊天切换 | 两个工作模式互斥；返回后保留当前文件和会话 | 普通 |
| `FIL-WORKBENCH-002` | 打开/关闭助手面板，拖拽助手宽度 | 面板显示、关闭和宽度持久化；内容不遮挡文件编辑器 | 普通 |

## 编辑、创建和下载

| 用例 ID | 操作 | 预期结果 | 级别 |
|---|---|---|---|
| `FIL-EDIT-001` | 打开文本/代码文件，点击编辑、输入内容、保存、取消 | 保存真实写回磁盘；取消丢弃草稿；刷新内容一致 | 普通 |
| `FIL-EDIT-002` | 点击新建文件，填写路径/内容，确认和取消 | 确认创建文件并打开；取消不创建；非法路径显示错误 | 创建 |
| `FIL-EDIT-003` | 点击下载 | 浏览器下载文件名、大小和内容与磁盘一致 | 普通 |
| `FIL-OPEN-001` | 点击文件路径复制、外部打开 | 剪贴板/外部打开动作符合当前平台；路径无越界 | 普通 |

## 预览与上传

| 用例 ID | 操作 | 预期结果 | 级别 |
|---|---|---|---|
| `FIL-PREVIEW-001` | 打开 PNG，点击预览关闭 | 图片像素可见；关闭后回到文件区 | 普通 |
| `FIL-PREVIEW-002` | 打开 PDF，翻页/关闭 | PDF worker 正常加载；页码和关闭按钮工作 | 普通 |
| `FIL-PREVIEW-003` | 打开 DOCX/XLSX/PPTX | Office 预览内容可见；服务失败时显示错误和恢复/关闭按钮 | 普通 |
| `FIL-PREVIEW-004` | 打开 ZIP/不支持扩展名/损坏文件 | 显示合理下载或错误状态；关闭和重新选择可用 | 普通 |
| `FIL-UPLOAD-001` | 通过文件选择和拖拽上传文件，点击上传项删除 | 真实 multipart 上传、进度、完成和删除均同步文件树 | 普通 |
| `FIL-ERROR-001` | 打开不存在、只读、无权限和超大文件 | 错误信息准确；重试、关闭、返回按钮恢复工作区；不修改原文件 | 普通 |

## 验收与清理

每个保存/创建/上传/下载用例必须同时检查 UI 和磁盘。测试结束删除创建的文件和目录；只读权限恢复后再删除临时目录。
