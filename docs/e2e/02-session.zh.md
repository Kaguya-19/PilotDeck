# 会话真实 E2E 用例

## 范围与前置

Onboarding 已完成，隔离 workspace 中至少有 General 项目、一个普通项目、两个会话和一个可引用的文件。所有聊天请求都使用真实 LLM Center，OpenAI、Claude、Gemini 分别覆盖发送、停止/完成、刷新和模型选择。

## 导航、项目和会话

| 用例 ID | 操作 | 预期结果 | 级别 |
|---|---|---|---|
| `SES-SIDEBAR-001` | 点击新对话 | 创建空会话并选中，URL、标题和列表同步 | 普通 |
| `SES-SIDEBAR-002` | 点击新项目，填写名称/路径，确认和取消 | 确认创建真实项目；取消不建目录；项目出现在列表 | 创建/普通 |
| `SES-SIDEBAR-003` | 点击项目、会话、General | URL 和主内容切换；选中态唯一且刷新可恢复 | 普通 |
| `SES-SIDEBAR-004` | 点击项目/会话展开、收起和加载更多 | 子项可见性、分页和 loading 状态正确；无重复项 | 普通 |
| `SES-SIDEBAR-005` | 点击项目/会话重命名，输入新名称后确认/取消 | 确认持久化新名称；取消恢复原名称 | 普通 |
| `SES-SIDEBAR-006` | 打开项目/会话右键菜单，点击删除、确认或取消 | 取消不删除；确认后列表、URL、文件和服务端状态同步 | 删除 |
| `SES-SIDEBAR-007` | 点击设置、技能、Dashboard、Memory、Always-On、定时任务入口 | 对应页面/弹层打开；返回主会话后原会话选择保持 | 普通 |
| `SES-SIDEBAR-008` | 点击收起/展开侧边栏，拖拽宽度和项目/会话分隔条 | 视觉状态、可操作区域和 localStorage 持久化；窄宽度仍可访问按钮 | 普通 |

## 会话头部和输入区

| 用例 ID | 操作 | 预期结果 | 模型/级别 |
|---|---|---|---|
| `SES-HEADER-001` | 点击会话标题编辑，保存/取消 | 标题更新或恢复；列表同步 | 协议无关/普通 |
| `SES-HEADER-002` | 点击搜索当前会话，输入关键词，关闭/清空 | 命中高亮、上一条/下一条和关闭按钮工作 | 协议无关/普通 |
| `SES-MODEL-001` | 打开模型选择器，切换 Auto 和三个真实模型 | 选中态、可用性和当前模型显示正确；发送使用选中快照 | OpenAI/Claude/Gemini |
| `SES-COMPOSER-001` | 输入唯一标记并点击发送或按 Enter | 真实请求发出；消息流结束；assistant 回复和模型名称显示 | OpenAI/Claude/Gemini |
| `SES-COMPOSER-002` | 流式生成时点击停止，再点击发送/重试 | 当前请求中止；UI 恢复可输入；重试只产生预期新 turn | 三种模型/普通 |
| `SES-COMPOSER-003` | 生成期间发送第二条，点击队列置顶、删除、暂停、恢复、steer | 队列顺序、状态和最终消息与操作一致 | 协议无关/普通 |
| `SES-ATTACH-001` | 选择文本、图片、PDF、Office 文件，等待上传完成，点击删除 | 上传进度和完成态正确；删除后请求不携带附件 | 协议无关/普通 |
| `SES-MSG-001` | 对用户/assistant 消息点击复制、复制格式菜单各选项 | 剪贴板内容符合格式；菜单可关闭 | 协议无关/普通 |
| `SES-MSG-002` | 点击重试、编辑并重新发送 | 旧 turn 和新 turn 关系正确；最终内容与输入一致 | 三种模型 |
| `SES-MSG-003` | 点击 fork，在用户消息入口选择 fork，确认/取消 | 确认创建新会话并携带历史；取消不创建 | 创建/普通 |
| `SES-MSG-004` | 点击图片预览、关闭、上一张、下一张 | Lightbox 打开、导航和关闭正确 | 普通 |
| `SES-INTERACTIVE-001` | 对权限请求点击允许、拒绝、批量处理 | 权限状态写入；工具执行/阻止结果可见 | 普通 |
| `SES-INTERACTIVE-002` | 对计划点击展开、收起、批准/拒绝 | 计划状态和后续消息正确 | 普通 |
| `SES-INTERACTIVE-003` | Ask User 点击问题导航、选项、提交 | 选择状态、必填校验和提交结果正确 | 普通 |

## 错误和恢复

验证 Gateway 断开、WebSocket 重连、模型限流、模型返回错误、附件失败、无权限项目和过期会话。每个错误按钮都要点击重试/关闭/返回，并断言不会产生重复消息、重复会话或丢失草稿。

## 清理

删除本用例创建的项目、会话和附件；保留失败 trace。隔离 HOME 在整个测试批次结束后删除。
