# 技能真实 E2E 用例

## 测试数据

准备 user scope 和 project scope 两组真实技能目录，每个技能包含合法 `SKILL.md` 和一个可验证资源。另准备无效 frontmatter、重复 slug、缺失正文和导入失败目录。

## 列表、scope 和安装

| 用例 ID | 操作 | 预期结果 | 级别 |
|---|---|---|---|
| `SKL-LIST-001` | 打开技能页，点击刷新、技能卡片 | 列表刷新；详情正确；选中态唯一 | 普通 |
| `SKL-SCOPE-001` | 点击 user/project scope | 列表、可用操作和保存路径切换；project 无项目时禁用并提示 | 普通 |
| `SKL-INSTALL-001` | 打开安装弹窗，搜索技能，点击安装 | 真实安装到选定 scope；列表刷新；文件存在 | 创建 |
| `SKL-INSTALL-002` | 对已存在技能点击强制安装 | 确认后真实覆盖；取消不覆盖；版本/内容更新 | 创建 |
| `SKL-INSTALL-003` | 制造网络或源错误，点击失败重试 | 错误可见；重试再次请求；失败不留下半成品 | 普通 |

## 导入

| 用例 ID | 操作 | 预期结果 | 级别 |
|---|---|---|---|
| `SKL-IMPORT-001` | 打开导入，点击选择目录、扫描 | 真实目录选择和扫描结果出现；无效目录显示原因 | 普通 |
| `SKL-IMPORT-002` | 点击全选/取消全选、单目录选择、清除已选、清除批量 | 选择计数和候选状态正确；清除不修改磁盘 | 普通 |
| `SKL-IMPORT-003` | 切换 copy/symlink、force、scope，点击导入、取消 | 导入方式和目标 scope 正确；取消不导入；确认后文件/链接关系可检查 | 创建 |

## 创建和编辑

| 用例 ID | 操作 | 预期结果 | 级别 |
|---|---|---|---|
| `SKL-CREATE-001` | 点击新建，填写 slug、名称、描述、正文，提交/取消 | 合法内容创建技能；取消不写文件；列表可打开详情 | 创建 |
| `SKL-CREATE-002` | 分别提交空 slug、非法 slug、重复 slug、空正文 | 对应字段错误可见；不发起成功写入 | 普通 |
| `SKL-EDIT-001` | 点击编辑，修改正文，点击保存/取消 | 保存真实更新 `SKILL.md`；取消恢复原内容 | 普通 |
| `SKL-EDIT-002` | 点击创建 user override、revert | override 文件生成/删除；revert 后回到继承内容 | 创建/删除 |
| `SKL-DELETE-001` | 点击删除，确认或取消 | 取消保留技能；确认删除对应 scope 文件，其他 scope 不受影响 | 删除 |

## 弹窗按钮清单

安装、导入、创建、编辑和删除弹窗中的关闭、取消、确认、提交、刷新、目录选择、扫描、清除、批量操作按钮都必须有独立点击断言。确认类按钮需要检查后端结果和文件系统结果，不得只验证 modal 消失。
